## Projects

- [legacy_code](https://github.com/joaoemanuelzilli/legacy_code): RAG system for equities research, with ingestion from public sources (CVM, SEC EDGAR, Bacen), hybrid retrieval (BM25 + embeddings), mandatory citations, refusal when evidence is missing and an evaluation harness.
- [quem-ganha](https://github.com/joaoemanuelzilli/quem-ganha): live forecast of Brazil's 2026 presidential runoff, using a per-municipality Bayesian model trained on 15 real vote counts. It called the winner with 5% of ballots counted.
- [e-agora](https://github.com/joaoemanuelzilli/e-agora): post-election valuation study of Brazilian stocks, with a CVM/B3 data pipeline, DCF and DDM models, Monte Carlo simulation, an event study and a live dashboard.
- [aulas_quant](https://github.com/joaoemanuelzilli/aulas_quant): course material for the Quantitative Research Division.
